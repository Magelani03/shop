# Folder Structure

This document explains what each main folder in the project is for and what lives inside it.

---

## Project root

| File / folder       | Purpose |
|---------------------|--------|
| **api/**            | Vercel serverless entry: all `/api/*` requests are handled here. |
| **dist/**           | Build output: the compiled frontend (HTML, JS, CSS) after `npm run build`. Deployed to Cloudflare Pages. |
| **node_modules/**   | Installed dependencies (from `package.json`). Don’t edit; regenerated by `npm install`. |
| **prisma/**         | Database schema, migrations, seed script, and SQL helpers. |
| **public/**         | Static assets served as-is (e.g. favicon, `robots.txt`). |
| **scripts/**        | Deployment and utility scripts (e.g. deploy to Pages). |
| **server/**         | Backend application code: Hono app, routes, middleware, env helpers. |
| **src/**            | Frontend source: React app, pages, components, styles, API client. |
| **.wrangler/**      | Cloudflare Wrangler local/dev cache. Safe to ignore or delete for a clean dev state. |
| **index.html**      | Single HTML entry for the Vite/React app. |
| **package.json**    | Project name, scripts, and dependencies. |
| **vite.config.ts**  | Vite config: entry, aliases, build options. |
| **tsconfig.json**   | TypeScript config for the whole project. |
| **vercel.json**     | Vercel config: framework, output dir, env, headers (e.g. CORS). |
| **render.yaml**     | Render Blueprint: defines the backend Web Service (build/start commands, env vars). |
| **prisma.config.ts** | Prisma config (e.g. for seed); can override schema path and env. |
| **.env**            | Local environment variables (not committed). See `.env.example` if present. |

---

## api/

Entry point for the API when deployed on **Vercel**.

| Item | Purpose |
|------|--------|
| **[[...path]].ts** | Catch-all serverless handler. Imports the Hono app from `server/app-vercel.ts` and forwards every request to it. So `/api/health`, `/api/auth/login`, `/api/products`, etc. all go through this file. |
| **README.md**      | Short notes on how the API is deployed and what env vars to set. |

---

## server/

Backend logic: one Hono app, routes, middleware, and shared helpers.

| Item | Purpose |
|------|--------|
| **app-vercel.ts** | Main Hono app (used by both Vercel and Render): CORS, injects Prisma/JWT/origins, mounts routes under `/api/*`. |
| **render.ts**     | Node server entry for **Render** (and local `npm run start:server`): runs the same Hono app on `PORT`. |
| **env.ts**        | Helpers to read `JWT_SECRET` and `ALLOWED_ORIGINS` from the request context (used by routes and middleware). |
| **prisma.ts**     | (If present) Prisma client setup or helpers. |
| **types.d.ts**    | Shared TypeScript types for the server. |
| **middleware/**  | Reusable middleware (e.g. **auth.ts**: JWT verification, `requireAdmin`). |
| **routes/**      | Route modules mounted in `app-vercel.ts`: **auth.ts** (login, register), **products.ts**, **orders.ts**, **settings.ts**, **admin.ts**. |
| **schemas/**     | Validation schemas (e.g. request body shapes) used by routes. |

---

## src/

Frontend source: React + Vite + React Router. This is the code that becomes the static site in **dist/**.

| Item | Purpose |
|------|--------|
| **main.tsx**   | Entry point: mounts the React app into `index.html`. |
| **App.tsx**    | Root component: router, routes (/, /products, /cart, /admin, etc.), and global UI (toast, cart drawer, auth modal). |
| **index.css**  | Global styles and Tailwind/theme. |
| **assets/**   | Images and other static assets used by the frontend. |
| **components/** | Reusable UI building blocks. |
| **hooks/**    | Custom React hooks (e.g. toast). |
| **lib/**      | Shared frontend logic: API client, store (auth, cart, admin). |
| **pages/**    | Page components; each usually corresponds to a route. |

### src/components/

| Subfolder / file | Purpose |
|------------------|--------|
| **layout/**   | Layout pieces: **Navbar**, **Footer**, **Sidebar**, **Layout**, **SidebarLayout**. |
| **ui/**       | Low-level UI primitives (buttons, inputs, dialogs, etc.), often from shadcn/ui. |
| **home/**    | Sections used on the homepage (e.g. **BrandValues**). |
| **AuthModal.tsx**  | Modal for login/signup. |
| **CartDrawer.tsx**  | Slide-out cart. |

### src/lib/

| File | Purpose |
|------|--------|
| **api.ts**  | Functions that call the backend (e.g. `login`, `getProducts`, `createOrder`). Uses `VITE_API_ORIGIN`. |
| **store.ts** | Global state (e.g. Zustand): auth user, cart, admin data. |

### src/pages/

One component per main route.

| File / folder | Purpose |
|---------------|--------|
| **Index.tsx**   | Homepage. |
| **Products.tsx**, **ProductDetail.tsx** | Product listing and product page. |
| **Cart.tsx**, **Checkout.tsx** | Cart and checkout flow. |
| **Profile.tsx** | User profile. |
| **About.tsx**, **Contact.tsx**, **Sales.tsx** | Static/marketing-style pages. |
| **Auth/Login.tsx**, **Auth/SignUp.tsx** | Login and registration. |
| **Admin/**      | Admin-only pages: **Dashboard**, **Orders**, **Products**, **Users**, **Analytics**. |
| **NotFound.tsx** | 404 page. |

---

## prisma/

Everything related to the database schema and data.

| Item | Purpose |
|------|--------|
| **schema.prisma** | Data model: tables (Product, User, Order, etc.), enums, relations. Single source of truth for the DB shape. |
| **seed.ts**       | Seed script: creates initial admin user, sample products, settings. Run with `npx prisma db seed`. |
| **migrations/**   | Generated migration SQL and history. Used by `prisma migrate`. |
| **init-neon.sql** | Manual SQL to create tables/enums in Neon (e.g. when you can’t run `prisma db push` from your machine). |
| **reset-neon.sql** | SQL to reset the Neon DB (drop schema, recreate) before a clean push or init. |

---

## public/

Static files that are copied as-is into **dist/** and served at the root (e.g. `/robots.txt`). Put favicon, PWA assets, or other non-built files here.

---

## scripts/

| File | Purpose |
|------|--------|
| **deploy.ps1** | Builds the frontend with `VITE_API_ORIGIN` and deploys **dist/** to Cloudflare Pages. Run from project root. |

---

## dist/ (build output)

Created by `npm run build`. Contains the production frontend (HTML, JS, CSS). This folder is what gets deployed to Cloudflare Pages; do not edit by hand.

---

## Summary diagram

```
shop/
├── api/              → Vercel entry (catch-all for /api/*)
├── server/           → Backend: Hono app, routes, middleware
├── src/              → Frontend: React app, pages, components, lib
│   ├── components/   → UI (layout, ui, home) + AuthModal, CartDrawer
│   ├── lib/          → api.ts, store.ts
│   └── pages/        → Route pages (Index, Cart, Admin, Auth, …)
├── prisma/           → Schema, migrations, seed, SQL helpers
├── public/           → Static assets
├── scripts/          → Deploy script (e.g. deploy.ps1)
├── dist/             → Build output (deployed to Pages)
└── [config files]     → package.json, vite.config.ts, vercel.json, etc.
```
